PRD

데이터 분석 자동화 프로그램은 업로드된 데이터셋에 대해 탐색, 전처리, EDA, 시각화, 인사이트 도출을 자동으로 수행하는 도구다.

항목내용
목표초기 데이터 분석 시간을 줄이고 분석 초안을 자동 생성한다.
사용자분석가, 실무자, 입문자
핵심 기능기본개요, 전처리 진단, 전처리 실행, EDA, 시각화, 인사이트
성공 기준데이터 업로드 후 분석 결과와 시각화를 빠르게 확인할 수 있어야 한다.

Architecture

현재 저장소가 비어 있으므로, 아래는 구현 기준의 권장 구조다.

project-root/
├─ backend/
│  ├─ app/
│  ├─ services/
│  ├─ analyzers/
│  ├─ preprocessors/
│  ├─ visualizers/
│  └─ reporters/
├─ frontend/
└─ docs/
모듈역할
analyzers기본개요, 통계 요약, 그룹 분석
preprocessors결측치 처리, 형변환, 이상치 처리
visualizers차트 추천 및 그래프 생성
reportersMarkdown/HTML 결과물 생성

Operation

단계설명
1. 업로드CSV, Excel, Parquet 등 입력 파일을 올린다.
2. 탐색컬럼 구조, 결측치, 기초 통계를 확인한다.
3. 전처리전처리 계획 검토 후 실행한다.
4. EDA/시각화그룹 분석, 분포 비교, 관계 분석을 수행한다.
5. 인사이트핵심 발견 사항을 요약한 리포트를 확인한다.

자주 발생하는 문제는 파일 형식 오류, 인코딩 문제, 컬럼 타입 불일치, 결측치 과다, 시각화 실패다.
