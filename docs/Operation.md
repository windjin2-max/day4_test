# Operation

## 1. 실행 전 확인 사항
- 데이터 파일 형식을 확인한다.
- 컬럼명 중복 여부를 확인한다.
- 날짜/숫자/범주형 컬럼의 타입이 예상과 맞는지 확인한다.
- 분석 결과를 저장할 디렉터리 권한이 있는지 확인한다.

## 2. 기본 사용법
1. 데이터 파일을 업로드한다.
2. 데이터 탐색을 실행한다.
3. 전처리 필요 여부를 확인한다.
4. 전처리 계획을 검토한다.
5. 전처리를 실행한다.
6. EDA와 시각화를 생성한다.
7. 최종 인사이트를 확인한다.

## 3. 데이터 탐색 실행
- 업로드 파일 형식은 `csv`, `xls`, `xlsx`를 지원한다.
- 프론트의 `데이터 탐색` 페이지에서 파일을 선택하고 `탐색 실행`을 누른다.
- 결과 화면에서 기본 개요, 컬럼 분류, 품질 이슈, 샘플 데이터를 확인한다.

## 4. 리포트 다운로드
- 분석 결과가 나오면 `Markdown 리포트` 버튼으로 통합 리포트를 내려받을 수 있다.
- `JSON 요약` 버튼으로 구조화된 결과를 내려받을 수 있다.
- 다운로드된 리포트는 업로드 결과를 기반으로 자동 정리된다.

## 5. 운영 규칙
- 원본 데이터는 수정하지 않고 별도 저장한다.
- 전처리 결과는 버전별로 구분한다.
- 분석 로그는 단계별로 남긴다.
- 리포트는 Markdown과 HTML 두 형태로 관리한다.

## 6. 자주 발생하는 에러

### 6.1 파일 형식 오류
- 원인: 지원하지 않는 확장자 또는 손상된 파일
- 대응: CSV, Excel, Parquet 등 허용 형식으로 재업로드한다.

### 6.2 인코딩 문제
- 원인: 한글 CSV에서 인코딩이 맞지 않는 경우
- 대응: UTF-8, CP949 등을 점검한다.

### 6.3 컬럼 타입 불일치
- 원인: 숫자형이어야 하는 컬럼에 문자열이 섞인 경우
- 대응: 타입 정제 규칙을 추가하거나 수동 변환을 수행한다.

### 6.4 결측치 과다
- 원인: 특정 컬럼 또는 행에 결측치가 많음
- 대응: 제거, 대체, 유지 중 정책을 선택한다.

### 6.5 시각화 생성 실패
- 원인: 데이터가 너무 적거나 값 분포가 극단적인 경우
- 대응: 차트 유형을 변경하거나 필터 조건을 조정한다.

## 7. 운영 체크리스트
- 입력 데이터 백업 완료
- 분석 로그 생성 여부 확인
- 전처리 적용 전후 데이터 비교 확인
- 시각화 파일 저장 확인
- HTML 리포트 열람 가능 여부 확인

## 8. 권장 사용 시나리오
- 초기 데이터 검토
- 분석 전 품질 점검
- 보고서 초안 자동 생성
- 시각화 기반 커뮤니케이션 자료 제작

## 9. 향후 개선 포인트
- 실행 이력 저장
- 분석 템플릿 저장
- 사용자별 설정 프리셋
- 자동 알림 및 예약 실행
