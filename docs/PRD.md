# PRD

## 1. 제품 개요
데이터 분석 자동화 프로그램은 사용자가 업로드한 데이터셋에 대해 데이터 탐색, 전처리 판단, EDA, 시각화, 인사이트 도출까지의 흐름을 자동화하는 도구다.

목표는 반복적인 초기 분석 작업을 줄이고, 분석 초안과 리포트를 빠르게 생성하는 것이다.

## 2. 목표
- 데이터셋의 기본 정보를 자동으로 파악한다.
- 전처리 필요 여부를 진단하고, 전처리 계획과 코드를 생성한다.
- 전처리된 데이터를 기반으로 EDA를 수행한다.
- 인포그래픽용 시각화를 생성한다.
- 분석 내용을 바탕으로 인사이트를 정리한다.

## 3. 사용자
- 데이터 분석 입문자
- 반복적인 탐색과 전처리 작업을 줄이고 싶은 분석가
- 보고서 초안을 빠르게 만들고 싶은 실무자

## 4. 핵심 기능 요구사항

### 4.1 데이터 탐색
#### 4.1.1 목적
- 입력 데이터의 구조와 품질을 빠르게 파악할 수 있도록 한다.
- 전처리가 필요한지 판단할 수 있는 기초 정보를 제공한다.
- 이후 EDA와 시각화의 기준 데이터를 만든다.

#### 4.1.2 개발 순서
1. 파일 업로드 후 데이터프레임으로 읽는다.
2. 업로드 형식은 `csv`, `xls`, `xlsx`를 지원한다.
3. 파일 형식에 따라 적절한 읽기 엔진을 선택한다.
4. 컬럼명, 행 수, 열 수, 자료형, 결측치 수, 중복 행 수를 수집한다.
5. 숫자형, 범주형, 날짜형 컬럼을 자동 분류한다.
6. 숫자형 컬럼에 대해 평균, 표준편차, 최소값, 최대값, 분위수를 계산한다.
7. 범주형 컬럼에 대해 고유값 수, 최빈값, 빈도 상위 항목을 계산한다.
8. 데이터 품질 이슈를 자동 탐지한다.
9. 탐색 결과를 표와 요약 텍스트로 저장한다.

#### 4.1.3 구현 산출물
- 데이터 기본 개요 JSON
- 데이터 탐색 리포트 Markdown
- 프론트에서 보여줄 요약 카드 데이터
- 전처리 필요 여부 판단용 진단 데이터
- Google Colab 실행용 노트북 파일
- 다운로드 가능한 파이썬 코드 파일

#### 4.1.4 세부 기능
- 데이터셋 크기 확인
  - 총 행 수, 총 열 수, 메모리 사용량을 계산한다.
- 컬럼 프로파일링
  - 컬럼별 자료형과 결측치 비율, 고유값 수를 계산한다.
- 기초 통계 생성
  - 숫자형 컬럼의 분포를 요약한다.
  - 범주형 컬럼의 대표값과 빈도를 요약한다.
- 품질 점검
  - 중복 행, 이상한 타입 혼합, 결측치 과다, 상수형 컬럼을 점검한다.

#### 4.1.5 검증 기준
- 업로드된 데이터셋에 대해 최소한 행/열 수, 컬럼 목록, 자료형, 결측치 요약이 나온다.
- 숫자형과 범주형 컬럼이 자동으로 구분된다.
- 데이터 품질 이슈가 1개 이상 있으면 탐지 결과에 표시된다.
- 프론트 화면에서 요약 정보를 즉시 확인할 수 있다.

#### 4.1.6 개발 우선순위
1. 파일 읽기 및 데이터프레임 생성
2. 기본 메타 정보 수집
3. 자료형 자동 분류
4. 숫자형/범주형 요약 통계
5. 품질 이슈 탐지
6. 리포트 및 API 응답 정리

### 4.2 전처리 필요 여부 확인
#### 4.2.1 목적
- 데이터 탐색 결과를 바탕으로 전처리가 필요한지 빠르게 판단한다.
- 전처리 우선순위를 자동으로 제안한다.
- 전처리 계획과 코드 생성을 위한 입력값을 만든다.

#### 4.2.2 개발 순서
1. 데이터 탐색 결과를 입력으로 받는다.
2. 결측치 비율이 높은 컬럼을 우선 식별한다.
3. 중복 행이 있는지 확인한다.
4. 자료형 불일치 또는 문자열로 들어온 숫자/날짜 후보를 찾는다.
5. 이상치 가능성이 높은 숫자형 컬럼을 점검한다.
6. 고카디널리티 범주형 컬럼을 점검한다.
7. 상수형 컬럼, 낮은 분산 컬럼, 제거 후보 컬럼을 확인한다.
8. 전처리 필요 여부를 `필수`, `권장`, `선택`, `불필요`로 나눈다.
9. 전처리 순서를 문서화한다.
10. 전처리 결과를 저장하고 리포트로 내려받을 수 있게 한다.

#### 4.2.3 구현 산출물
- 전처리 진단 JSON
- 전처리 계획 Markdown
- 전처리 실행 코드 초안
- 전처리 전/후 비교 요약
- 다운로드 가능한 통합 리포트

#### 4.2.4 검증 기준
- 결측치, 중복, 타입 문제, 이상치 후보, 고카디널리티 항목이 구분되어 표시된다.
- 전처리 우선순위가 한눈에 보인다.
- 업로드 결과 기반 리포트를 다운로드할 수 있다.

#### 4.2.5 개발 우선순위
1. 전처리 필요성 진단 규칙 정의
2. 우선순위 분류 로직 구현
3. 전처리 계획서 생성
4. 리포트 통합 및 다운로드 기능 연결

### 4.3 EDA
- 전처리 완료 데이터를 바탕으로 그룹별 분포와 요약 통계를 분석한다.
- 변수 간 관계를 확인한다.
- 상관분석, 교차분석, 분산 비교, 분포 비교 등의 분석 포인트를 발굴한다.
- 분석 결과를 테이블과 텍스트로 정리한다.

### 4.4 시각화
- 인포그래픽에 적합한 그래프를 생성한다.
- 데이터 특성에 따라 적절한 차트를 추천한다.
- 분포, 추세, 비교, 관계, 구성 비율을 시각화한다.
- 생성된 그래프를 저장하거나 보고서에 삽입할 수 있어야 한다.

### 4.5 인사이트 도출
- EDA와 시각화 결과를 기반으로 핵심 발견 사항을 요약한다.
- 이상 징후, 주요 패턴, 개선 포인트를 정리한다.
- 다음 분석 단계 또는 의사결정 포인트를 제안한다.

## 5. 비기능 요구사항
- 재현 가능성: 같은 입력과 동일 설정에서 동일 결과를 생성할 수 있어야 한다.
- 확장성: 새로운 전처리 규칙이나 시각화 유형을 추가하기 쉬워야 한다.
- 유지보수성: 기능별 모듈 분리가 명확해야 한다.
- 가독성: 생성 결과는 사람이 바로 검토할 수 있어야 한다.
- 안정성: 데이터 크기나 결측치 패턴이 달라도 실패하지 않도록 예외 처리가 필요하다.

- 전처리 진단 리포트
- 전처리 계획서
- 전처리 코드
- EDA 리포트
- 시각화 이미지 또는 HTML 리포트
- 최종 인사이트 요약문

## 7. 성공 기준
- 업로드된 데이터셋에 대해 자동으로 요약 정보를 생성할 수 있다.
- 전처리 필요 여부를 판별하고 실행 가능한 코드를 제공할 수 있다.
- EDA와 시각화 결과를 통해 사용자가 빠르게 해석 가능한 결과를 얻을 수 있다.
- 최종적으로 분석 초안 작성 시간을 의미 있게 단축할 수 있다.
